# ADR 0001: Rust as the implementation language

- Status: accepted
- Date: 2026-08-05

## Context

turnout is a daily-driver CLI: it must install as a single binary on Windows, macOS and Linux, start instantly, run a long-lived local proxy reliably, and talk to OS-level facilities (keyring, clipboard). The author's existing tooling is Rust-based.

## Decision

Implement turnout in Rust. Core crates: clap (CLI), dialoguer (wizards), directories (data paths), keyring (secrets), arboard (clipboard), hyper/axum (gateway).

## Consequences

- Single static binary, no runtime dependencies for end users.
- Cross-platform CI must test on all three OSes - keyring and paths are platform-specific.
- Slower iteration than a scripting language; acceptable for a long-lived tool.
